The absence of raw registry addresses is a **redistribution-permission gap**, not a claim that public browsing is prohibited or that an author can grant third-party rights. The public numerical tables contain no street address, full source response, telephone/contact record or precise source point. Users can retrieve source identities using the channels above, subject to provider terms and availability. No paid access requirement, embargo, application deadline or executed data-use agreement is documented in this project.

The derived numerical package does not require address access to rerun the optimization and sensitivity results. A full reconstruction from source geometries requires source records, coordinate interpretation, manually reviewed eligibility decisions and historical road snapshots. Online retrieval may return changed records and is not an exact replacement for frozen inputs.

ASPECT unit interpretation: provider prose labels densities as persons per hectare, while the source allocation code and district-total checks motivate the manuscript's persons-per-native-cell interpretation. The public weights reproduce the latter; they do not silently substitute a different population model. See [REPRODUCIBILITY.md](REPRODUCIBILITY.md).
